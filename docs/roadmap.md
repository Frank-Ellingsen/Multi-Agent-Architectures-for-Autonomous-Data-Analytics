# Project roadmap

## Phase 1: Foundation

- finalize the analytical workflow and sequencing
- align each skill to a clear business outcome
- define the data contracts that pass from one stage to the next

## Phase 2: Implementation

- turn the skill catalog into prompts, orchestrations, or agent tasks
- add model-selection logic for forecasting and scenario evaluation
- introduce traceable evidence and output logging

## Phase 3: Productionization

- connect skills to real data pipelines and target systems
- add dashboard and reporting automation
- integrate automated validation and release workflows before publishing
